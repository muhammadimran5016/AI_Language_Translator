# 🌍 AI Language Translator

An AI-powered language translation application built with Python and Streamlit. The application allows users to translate text between multiple languages instantly, listen to translated text using text-to-speech, download translations, view translation history, and analyze translation statistics through an interactive dashboard.

---

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔊 Convert translated text to speech
- 📥 Download translated text as a file
- 📜 Save and view translation history
- 📊 Analytics dashboard with translation statistics
- 🎨 Modern and user-friendly interface
- ⚡ Fast and lightweight Streamlit application

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/muhammadimran5016/AI_Language_Translator.git
```

### 2. Navigate to the project folder

```bash
cd AI_Language_Translator
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows**

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run app.py
```
