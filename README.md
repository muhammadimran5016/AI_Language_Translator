# 🌍 AI Language Translator

An AI-powered language translation application built with Python and Streamlit. The application allows users to translate text between multiple languages, listen to translated text using text-to-speech, download translations, view translation history, and analyze translation statistics through an interactive dashboard.

---

## ✨ Features

- 🌐 Translate text between multiple languages
- 🔊 Convert translated text to speech
- 📥 Download translated text as a file
- 📜 Save and view translation history
- 📊 Analytics dashboard with translation statistics
- 🎨 Modern and user-friendly interface
- ⚡ Fast and lightweight Streamlit application




---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| Python | Core programming language |
| Streamlit | Interactive web application framework |
| deep-translator | Language translation |
| gTTS | Text-to-Speech conversion |
| Pandas | Translation history management |
| Matplotlib | Analytics and data visualization |
| CSV | Store translation history |
